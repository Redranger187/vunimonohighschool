Website Editing User Guide

This illustrated guide explains how to update the Vunimono High School website through JSON files and the staff CMS. Normal updates should not require editing HTML.

1. Edit school identity

Open content/site.json to change the school name, motto, mission, vision, theme, values, contact information and external links. Keep the JSON format valid: use double quotation marks and commas between items.

School Settings

2. Edit a page

Each page has a matching file in content/pages/, such as home.json, academics.json or contact.json. Change the title, introduction, section text, links or image paths there. The HTML file is a display template and should not need routine editing.

3. Publish a news update

Use content/news.json or the Staff CMS under /admin/. Add a unique ID, date, category, title, summary, full body and image path. Keep older stories in the file so the news archive remains available.

4. Replace an image

Images are organised by page under assets/images/. For example, homepage images are in assets/images/home/, principal images in assets/images/principal/, and news images in assets/images/news/. Upload the image into the correct folder and update the JSON image path exactly.

Cloudflare Pages deployment

Upload the contents of this project folder to the root of your GitHub repository. In Cloudflare Pages, connect that repository, set the production branch to main, use build command exit 0, and set the build output directory to the repository root (/). Cloudflare Pages serves the top-level index.html as the homepage.

How publishing works

Commit or save the changed JSON and image files to GitHub. Cloudflare Pages deploys the repository and publishes the changes. The static site uses relative file paths, so it can be deployed from the repository root without a framework build step.

Important: If the page shows a data-loading error, validate the JSON syntax and check the browser’s Network panel for a missing file. Do not leave a “Loading…” message as the final content.
